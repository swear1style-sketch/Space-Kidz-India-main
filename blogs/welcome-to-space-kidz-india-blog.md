Welcome to the official Space Kidz India blog.

This page reads all markdown files from the blogs folder.

## Add images from public/img/blogs

Use a markdown image like this:

![Students at workshop](/img/blogs/students-workshop.jpg)

Any image placed inside public/img/blogs can be rendered in markdown content.

## Add links and lists

- Write posts in standard markdown.
- Use headings, lists, tables, and code blocks.
- New files are picked up automatically.
